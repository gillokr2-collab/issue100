# 이슈100 MVP 아키텍처

프론트엔드(Next.js App Router)는 Spring Boot 공개 API를 호출합니다. 백엔드는 이슈, 검색, 분석, 랭킹, 수집 도메인을 분리한 단일 애플리케이션입니다. PostgreSQL은 기사·이슈·검색·조회 이벤트와 스냅숏을 저장하고 Redis는 운영 단계에서 방문·검색 중복 방지 TTL 키와 캐시를 담당합니다.

관심도 점수는 기사 증가 속도 25%, 참여 언론사 20%, 기사 수 15%, 순방문 조회 15%, 조회 증가 속도 10%, 원문 클릭 5%, 내부 검색 5%, 최신성 5%로 계산합니다. 외부 언론사의 비공개 조회수는 사용하지 않습니다.

Mock Provider는 API 키가 없는 local/dev/default 프로필에서 활성화됩니다. 실제 Provider는 `NewsProvider` 인터페이스를 구현하고 별도 프로필로 등록합니다.

현재 중복 방지는 실행 중 메모리 저장소로 동작하며 API 계약과 시간 규칙을 검증합니다. 운영 구현에서는 동일 키 구조를 Redis `SET NX EX`로 교체해야 다중 인스턴스에서도 일관성이 보장됩니다.
